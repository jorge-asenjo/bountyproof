# Juice Shop Lab (practice program)

A fictional program brief for the bountyproof demo lab. Paste it when Phase 0 asks for the program page.

## Scope
- In scope: `http://localhost:3000` (OWASP Juice Shop, running in Docker on this machine).
- Out of scope: every other host.

## Rules of engagement
- Every request carries the user agent tag `bountyproof-lab`.
- No denial of service and no brute forcing.
- Use accounts you register in the lab yourself.
- AI assistance: allowed.

## Rewards (fictional)
| Severity | Reward |
|---|---|
| Critical | 2,000 |
| High | 1,000 |
| Medium | 400 |
| Low | 100 |

## Not eligible
- Missing security headers, clickjacking, self-XSS, rate limiting.
